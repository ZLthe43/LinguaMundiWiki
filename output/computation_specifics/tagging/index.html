Tagging

This section deals with the tag and magazine structures. The tag is a structure that can store exactly one species, and can be read or written to at any time. The magazine is a queue that serves as a buffer for results. It only activates if a spell receives multiple results from effect glyphs (not relevant for simple spells).

Write Tag

$(n)A →
Pops a species and passes it into the tag. It will remain in the tag until either the tag is written to again or the spell ends.

Read Tag

→ $(n)A
Reads the tag and pushes a copy of the contained species. The original species remains in the tag.

Poll Magazine

→ $(n)result
The magazine, as a queue, releases the results in the order they were received. This glyph removes the oldest result from the magazine and pushes it into the capsum.

Magazine List

→ $(n)list
Takes all items in the magazine, and adds them to a list from oldest to newest. The list is then pushed onto the capsum.

Magazine Size

→ $(n)number
Pushes onto the capsum a number corresponding to the number of elements held in the magazine.
